# Contributing

1. Fork this repository and create a branch.
2. Run `npm ci` and `npm run dev`.
3. Keep mission facts tied to original NASA sources, retain image credits and distinguish planned goals from achieved results.
4. Keep Stories, Equipment, Archive and Still Exploring as separate experiences. Active missions must not be given invented endings.
5. Build with `npm run build`. Check phone and desktop layouts, scene navigation, direct links, missing images and horizontal overflow. Include screenshots and a short explanation in your PR.
6. Open a pull request for the project owner to review and merge. Do not change deployment, add paid services, introduce credentials or widen media licenses without approval.

Asset changes need a new credited source entry and a rebuilt asset bundle with updated manifest checksums. Do not commit credentials, private data, node_modules or generated dist files.
